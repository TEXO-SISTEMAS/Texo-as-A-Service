  Paleta de colores:
  - Fondos oscuros: #0a0e1a, #0d1220, #121829
  - Azul corporativo: #3b82f6, #2563eb
  - Textos: blanco, #c5cad4, #7c8597, #5f6b7f

  1. Sidebar (300px) con logo, botón "Nueva conversación", sugerencias y footer
  2. Header con badge de sesión e info del usuario
  3. Body centrado con estado vacío y cards de capacidades
  4. Input area fijo abajo con textarea auto-redimensionable
  5. Footer con branding

  Estrategia de reutilización propuesta:
  - Crear base.css con variables CSS y componentes compartidos
  - Crear archivos específicos por página (chat.css, upload.css, dashboard.css)
  - Utilidades JS compartidas (utils.js)

  1. Cree la página de upload siguiendo este diseño
  2. Extraiga el CSS base a un archivo separado
  3. Implemente alguna otra parte del sistema
